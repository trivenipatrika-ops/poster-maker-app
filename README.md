# Poster / Banner Maker App

Ek simple, offline poster/banner banane wala Android app - Python (Kivy) se bana.
Ismein koi admin panel nahi hai.

## App Kya Karta Hai
- User apna theme (color) chunta hai
- User apni photo upload karta hai
- User chahe to apna khud ka logo/chinh upload kar sakta hai
- Title, subtitle, footer text likh kar poster banta hai

## Legal Jimmedari
Yah app khud koi party ka chinh ya logo nahi deta. User jo apna
logo/chinh upload karta hai, uska sahi istemal karne ki jimmedari
user ki khud ki hai.
